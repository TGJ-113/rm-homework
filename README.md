### task5-1 呼吸灯算法

- 占空比 = 0.5·sin(3.14t − 3.14/2) + 0.5（正弦函数过渡更平滑）
- PSC = 71，ARR = 999（用的 TIM2）
- CCR = 占空比 × (ARR + 1)

### task5-2 舵机算法

- 占空比 = 转动所需电平持续时间 / 周期，根据舵机参数推出周期 = 20 ms（50 Hz）
- 占空比 = 0.075 − 0.05·cos(3.14t)，范围 2.5% ~ 12.5%（因为改成 50 Hz，所以占空比跟着改了）
- PSC = 71，ARR = 19999（用的 TIM3）
- CCR = 占空比 × (ARR + 1)
- 角度 = (CCR − 500) × 180 / 2000

> 备注：原先认为两个功能可以分开做，所以代码里最开始标的是 task5-1，后来发现需要合在一起就没再改名。
